# 오픈소스소프트웨어 팀 과제 — LEGEND GOMOKU

2025년 2학기 오픈소스소프트웨어 수업 팀 과제로 제작한 웹 오목 게임입니다. Next.js와 TypeScript로 게임 화면과 대국 기능을 구성했습니다.

## 과제 내용

- AI 대전, 같은 기기에서의 2인 대전과 묘수 풀이
- 오목 게임 UI와 대국 흐름 구성
- GitHub를 이용한 팀 협업

## 출처와 기록

- [팀 원본 저장소](https://github.com/Choi-Juno/LegendProject-2025)
- 팀 과제의 Git 커밋 기록을 보존한 개인 보관본입니다. 팀 공동 작업물이며, 전체 기능을 개인 단독 기여로 표시하지 않습니다.

```sh
npm ci

```
